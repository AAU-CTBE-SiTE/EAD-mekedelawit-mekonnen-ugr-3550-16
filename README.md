# Spring Core - IoC & Bean Management Lab

A hands-on Java and Spring Framework project demonstrating core Inversion of Control (IoC), Dependency Injection (DI), and bean scoping configurations.

## Features Covered
* **Spring IoC Container:** Managing object lifecycles using `ClassPathXmlApplicationContext`.
* **Dependency Injection:**
  * **Setter Injection** & **Constructor Injection** for primitive values and custom objects (`Address`).
  * **Object Dependency Wiring** using XML configuration (`ref`).
* **Bean Scopes:** Understanding `singleton` vs `prototype` instantiation.

## Tech Stack
* **Language:** Java 19+ (or JDK 23)
* **Framework:** Spring Framework 6.2.7 (`spring-context`)
* **Build Tool:** Apache Maven
* **Libraries:** Project Lombok
